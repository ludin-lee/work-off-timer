# WorkOffTimer

macOS 메뉴바에 퇴근까지 남은 시간을 띄워 주는 작은 앱입니다.

```
퇴근까지 3:12:45
```

## 기능

- 앱을 처음 켠 시각을 그날의 출근 시간으로 저장합니다.
- 퇴근 시간은 출근 시간 + 9시간(근무 8시간 + 점심 1시간)입니다.
- 메뉴바에 남은 시간을 1초마다 갱신합니다. 퇴근 시간이 지나면 `퇴근! +0:05:12`처럼 초과 시간을 보여 줍니다.
- 메뉴에서 할 수 있는 것
  - 출근 시간 직접 설정
  - 퇴근 시간 직접 설정 (반차, 반반차 등)
  - 퇴근 시간을 기본값(+9시간)으로 되돌리기
- 설정한 값은 그날 하루만 쓰이고 다음 날에는 초기화됩니다.
- Dock에는 아이콘이 뜨지 않고 메뉴바에만 나타납니다.

## 빌드

Xcode Command Line Tools(`swiftc`)가 필요합니다.

```sh
xcode-select --install   # 처음 한 번만
./build.sh
```

`WorkOffTimer.app`이 만들어집니다.

## 실행

```sh
open WorkOffTimer.app
```

`/Applications`로 옮겨 두고 써도 됩니다. 로그인할 때 자동으로 켜지게 하려면 **시스템 설정 → 일반 → 로그인 항목**에 추가하세요.

서명하지 않은 앱이라 처음 열 때 macOS가 막을 수 있습니다. 그럴 때는 Finder에서 앱을 우클릭한 뒤 **열기**를 누르세요.

## 근무 시간 바꾸기

[main.swift](main.swift) 맨 위의 값을 고친 뒤 다시 빌드합니다.

```swift
let workSeconds: TimeInterval = 9 * 3600
```
